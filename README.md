# Privo — Zero-Trace Web Suite

> A modern, human-crafted, privacy-first portal for zero-database, client-side web tools by [Radhey Bhadja](https://github.com/Radhey-Bhadja).

---

## 🛡️ Overview

**Privo** is an open-source hub of ephemeral, peer-to-peer web utilities designed with absolute respect for user privacy. Everything executes directly inside your browser with **zero persistent databases**, **no accounts**, **no tracking**, and **immediate memory wipe** when you close the session.

---

## 🚀 The Suite

| Tool | Description | Live Deployment | Source Code |
| :--- | :--- | :--- | :--- |
| **Private Group Messenger** | End-to-end encrypted multi-user messaging via 6-digit room codes. Zero logs or database storage. | [Launch Chat](https://chatling-era-upg.vercel.app) | [chatling-upg](https://github.com/Radhey-Bhadja/chatling-upg) |
| **Private 1-on-1 Messenger** | Direct peer-to-peer instant messaging with auto-purging ephemeral rooms. | [Launch Chat](https://chatling-era.vercel.app) | [chatling](https://github.com/Radhey-Bhadja/chatling) |
| **Secure Group Video Calling** | WebRTC-powered multi-party audio & video rooms created with a simple link. | [Start Call](https://ghost-call-vc.vercel.app) | [GhostCall](https://github.com/Radhey-Bhadja/GhostCall) |
| **Instant Web QR Scanner** | Local computer-vision QR code decoder from camera or file uploads. Zero server uploads. | [Open Scanner](https://qrify-scan-lilac.vercel.app) | [QR](https://github.com/Radhey-Bhadja/QR) |

---

## 🛠️ Tech Stack & Architecture

- **Markup & Styling:** HTML5, Tailwind CSS, Plus Jakarta Sans, JetBrains Mono
- **Interactions:** Vanilla JavaScript (SPA structure with browser hash history)
- **Design Philosophy:** Neo-brutalist tactile design, clean responsive alignment, accessible contrast
- **Hosting:** Pure static client-side (GitHub Pages / Vercel / Netlify ready)
